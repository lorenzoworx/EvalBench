# Self-hosted fonts

- Bricolage Grotesque: [upstream license](https://raw.githubusercontent.com/google/fonts/main/ofl/bricolagegrotesque/OFL.txt), included as `bricolage-OFL.txt`.
- IBM Plex Sans: [upstream license](https://raw.githubusercontent.com/google/fonts/main/ofl/ibmplexsans/OFL.txt), included as `plex-OFL.txt`.
- IBM Plex Mono: [upstream license](https://raw.githubusercontent.com/google/fonts/main/ofl/ibmplexmono/OFL.txt), included as `mono-OFL.txt`.

Fonts retain their upstream names. WOFF2 packaging is used for browser delivery. These fonts are not sold separately.
